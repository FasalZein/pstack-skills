# pstack-skills

Public mirror of the `skills/` folder of the owner's pi-pstack repository (at bb03fac): Lauren Tan's [pstack](https://github.com/cursor/plugins/tree/main/pstack) skills, adapted to run in [pi](https://pi.dev) with [pi-subagents](https://github.com/FasalZein/pi-subagents).

Install all of them (recommended, because some skills use others):

```bash
npx skills add FasalZein/pstack-skills --skill '*' -g
```
